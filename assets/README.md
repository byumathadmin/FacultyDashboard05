# Building map images

Place the three floor-plan images in this folder with these exact names:

- `building-map-floor-1.png`
- `building-map-floor-2.png`
- `building-map-floor-3.png`

The dashboard shows a placeholder until each image is added.

## Faculty room directions

Place each faculty member's room-directions image in this folder as a PNG. Use
the same filename as the faculty profile HTML, with the `.png` extension; for
example, `Andrew_Pollington.png` or `Benjamin_Webb.png`.
